# Contributor contract

Write public documentation in English. Keep claims precise, dated, and supported by primary vendor, maintainer, or standards sources.

Do not add private incident history, private product or customer identifiers, local paths, hostnames, IP addresses, account IDs, secrets, production logs, or copied third-party content. Public vendor and product names are appropriate where needed for a sourced claim. Summarize external material and link to its authoritative source.

This repository must not include executable malware or exploit payloads, autorun content, automated host mutation, deployment credentials, or scripts that scan or update machines. Defensive incident-response guidance, read-only checks, and authorization boundaries are allowed.

Distinguish installed software from deployed and running software. State unknowns, vendor-owned limits, compatibility constraints, and recheck triggers explicitly. Require a positive and a controlled negative test when documenting certificate validation.
